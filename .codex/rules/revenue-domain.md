# Финансовая логика ExFlow

## Поток данных

1. Браузер вызывает `GET /api/exflow` без кеширования.
2. Route Handler читает серверные API-ключи.
3. Два финансовых источника и курсы валют запрашиваются параллельно.
4. `calculateTotalRevenue` валидирует, конвертирует и суммирует данные.
5. Клиент проверяет форму ответа, показывает результат, пишет лог и сохраняет краткую историю.

## Инварианты расчёта

Не меняй эти правила без явного изменения требований:

- Из первого источника учитываются только транзакции с `type`, равным `paid` без учёта регистра.
- Сумма первого источника должна быть конечным числом, а код валюты — непустой строкой.
- Второй источник разбирается из строк формата `<положительная сумма> <трёхбуквенная валюта>`.
- Коды валют нормализуются в верхний регистр.
- USD проходит без конвертации; другие суммы делятся на соответствующий курс с базой USD.
- Отсутствующий, бесконечный, `NaN`, нулевой или отрицательный курс приводит к пропуску операции и одному предупреждению на валюту.
- Подытоги источников и общий итог округляются до двух знаков.
- `processed`, `skipped`, `currencies`, `warnings`, `sources` и `total` должны оставаться согласованными.

## Границы функции расчёта

`calculateTotalRevenue` должна оставаться детерминированной и чистой:

- без сети и чтения env;
- без React и состояния интерфейса;
- без `window`, storage и других browser API;
- с защитой от некорректных удалённых данных.

При изменении расчёта проверь оба формата источников, `paid` в разном регистре, неправильные записи, неизвестные валюты, невалидные курсы и округление денежных значений.
