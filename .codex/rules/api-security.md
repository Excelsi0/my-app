# API, внешние сервисы и безопасность

## Серверные переменные

Live route использует:

- `EXFLOW_FINANCE_API_KEY`;
- `EXFLOW_RATES_API_KEY`.

Обе переменные являются только серверными. Не добавляй к ним `NEXT_PUBLIC_`, не сериализуй их в клиент, не выводи в логи и ответы, не помещай реальные значения в примеры и не коммить `.env.local`.

## Поведение `/api/exflow`

Если требования явно не изменились, сохраняй:

- `dynamic = "force-dynamic"`;
- `cache: "no-store"` для внешних запросов;
- таймаут 15 секунд;
- параллельный запрос источников и курсов;
- HTTP `503`, когда обязательная конфигурация отсутствует;
- HTTP `502` при сетевой, upstream- или parsing-ошибке;
- `Cache-Control: no-store` в успешном ответе.

Все удалённые JSON-данные недоверенные. Валидируй форму и типы перед использованием. Не передавай клиенту upstream payload, request headers, URL с ключом, stack trace или внутренние детали исключений.

## Ошибки и контракты

- Возвращай безопасные и понятные русские сообщения.
- Сохраняй согласованность HTTP-статуса и формы JSON-ответа.
- При изменении ответа синхронно обновляй клиентскую проверку формы и связанную документацию.
- Не кешируй live-финансовые данные без явного продуктового решения.
- Не выполняй live-проверку без валидных ключей и не подставляй вымышленные результаты.
